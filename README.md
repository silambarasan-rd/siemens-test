# Task Manager UI

## Overview

A task management application built with React and React Router, featuring user authentication and full task CRUD operations. Includes a JSON Server backend with custom auth middleware, demonstrating a complete auth flow with a responsive, mobile-first UI design.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in the development mode and runs the server as well.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser and use [http://localhost:4000](http://localhost:4000) to access endpoints by `json-server`.

we can add more data by adding changes to the `db.json` under `/server` folder.

### `npm run build`

Builds the app for production to the `build` folder.\
It correctly bundles React in production mode and optimizes the build for the best performance.

The build is minified and the filenames include the hashes.\
Your app is ready to be deployed!
